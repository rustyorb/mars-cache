Prepare now. Read offline later.

The website is the distribution point. The survival copy is the set of files stored on your own devices.

  1. Download the offline core and unzip the entire archive. Its 32 hosted references work locally immediately.
  2. While still online, run Prepare-Personal-Cache.cmd on Windows. Python 3 must be installed. On macOS/Linux, run python3 tools/prepare_personal.py from the unzipped folder.
  3. The tool reuses the core PDFs and downloads the remaining files directly from publishers. Your personal library goes in MARS-CACHE-Personal in your home folder.
  4. Open OFFLINE-READINESS.html there. It checks the 143 planned reference/chapter files and reports any missing downloads. Preparation is incomplete if files are missing.
  5. Disconnect Wi-Fi and mobile data. Practice finding maps and instructions. Keep another complete copy on a backup drive.

A publisher link or website bookmark is not an offline copy. The preparation tool needs internet access; it is meant to run before an outage. Publisher materials retain their terms and attribution.

The Raspberry Pi stage will serve these local files over its own Wi-Fi. This release does not yet install a Pi operating system.
